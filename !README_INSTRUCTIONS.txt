==============================================================================
[1] РАЗРАБОТКА (Локальный запуск)
==============================================================================
Чтобы не ломать сайт, проверяй всё у себя на компьютере.

1. Открой терминал в папке проекта и запусти сервер:
   npx vite
2. Перейди по ссылке (обычно http://localhost:5173).
3. Для остановки сервера нажми: Ctrl + C

==============================================================================
[2] СОХРАНЕНИЕ И ОБНОВЛЕНИЕ САЙТА (ПОЛНЫЙ ЦИКЛ)
==============================================================================
Когда код готов, выполняй эти команды строго по очереди:

1. СБОРКА ПРОЕКТА (обновление папки dist):
   npm run build

2. СОХРАНЕНИЕ В GIT (создание резервной копии в репозитории):
   git add .
   git commit -m "Описание того, что изменилось"
   git push origin master

3. ОТПРАВКА НА САЙТ (загрузка в интернет):
   firebase deploy

------------------------------------------------------------------------------
ВАЖНО: Картинки всегда должны лежать в папке "public".

==============================================================================
[3] ОБНОВЛЕНИЕ МОБИЛЬНОГО ПРИЛОЖЕНИЯ (ANDROID)
==============================================================================
Приложение работает автономно. Чтобы свежий код попал в телефон, его нужно
синхронизировать.

ШАГ 1: СИНХРОНИЗАЦИЯ КОДА
Убедись, что ты уже выполнил сборку (npm run build), затем введи:
   npx cap sync

(Команда 'sync' копирует готовый сайт внутрь папки Android).

ШАГ 2: СБОРКА ФАЙЛА (APK)
1. Открой Android Studio:
   npx cap open android
   (Или открой программу руками и выбери папку "android" внутри проекта).

2. СОЗДАНИЕ ФАЙЛА:
   - В Android Studio нажми два раза Shift. Это откроет поиск. Введи Generate Signed Bundle / APK
   - Выбери: APK -> Next.
   - Key store path: Выбери свой файл ключа (release-key.jks).
   - Введи пароли
   - Build Variants: Выбери "release".
   - Нажми Create.

3. ГДЕ ЗАБРАТЬ ФАЙЛ:
   Внизу справа появится уведомление. Нажми "locate".
   Или иди вручную: android/app/release/app-release.apk.

==============================================================================
[4] ТЕХНИЧЕСКИЙ ПЕРЕРЫВ (ЗАГЛУШКА)
==============================================================================
Если ты делаешь крупное обновление и хочешь закрыть сайт для посетителей.

КАК ВКЛЮЧИТЬ ЗАГЛУШКУ:
1. Открой терминал в СОСЕДНЕЙ папке "Maintenance".
2. Введи:
   firebase deploy

(Теперь на сайте висит "Мы обновляемся").

КАК ВЕРНУТЬ САЙТ ОБРАТНО:
1. Открой терминал в ОСНОВНОЙ папке проекта ("Editorial Safe App").
2. Убедись, что код собран:
   npm run build
3. Введи:
   firebase deploy

==============================================================================
[5] ПОЛЕЗНЫЕ КОМАНДЫ И РЕШЕНИЕ ПРОБЛЕМ
==============================================================================

А) ПРОПАЛА ИКОНКА ИЛИ ЗАСТАВКА
Если ты поменял logo.png в папке assets:
   npx capacitor-assets generate --iconBackgroundColor "#121212"
   npx cap sync

Б) ОШИБКА ПРИ СБОРКЕ САЙТА (Vite Error)
Проверь, не дублируются ли у тебя "export" в файле firebase-init.js.

==============================================================================
[6] ВАЖНЫЕ НАПОМИНАНИЯ (НЕ ПОТЕРЯЙ!)
==============================================================================
1. Файл ключа (release-key.jks или android.keystore).
   ХРАНИ ЕГО КАК ЗЕНИЦУ ОКА!

2. Пароль от ключа.

3. Файл google-services.json.
   Он лежит в папке android/app. Он нужен для уведомлений. Не удаляй его.

4. Файл assetlinks.json.
   Он лежит в public/.well-known/. Он нужен, чтобы приложение открывалось
   без верхней полоски браузера. Не удаляй его.

[7] НАЧАЛО РАБОТЫ НА НОВОМ КОМПЬЮТЕРЕ (ПЕРЕНОС ПРОЕКТА)
==============================================================================
Если ты пересел за другой ПК или переустановил систему:
1. УСТАНОВИ БАЗОВЫЙ СОФТ:
   - Node.js (версия LTS с официального сайта nodejs.org).
   - Git (с официального сайта git-scm.com).
   - Android Studio (если планируешь собирать APK).
2. СКАЧАЙ ПРОЕКТ И УСТАНОВИ ПАКЕТЫ:
   - Открой терминал и клонируй репозиторий:
     git clone https://github.com/gleb260111/editorial-board-shkolyar
   - Перейди в папку проекта и установи библиотеки:
     npm install
     npm install -g firebase-tools
3. АВТОРИЗУЙСЯ В СЕРВИСАХ:
   - Выполни вход в Firebase CLI:
     npx firebase-tools login
     (В открывшемся браузере подтверди вход через свой Google аккаунт).
4. ВЕРНИ ВАЖНЫЕ ФАЙЛЫ (они не хранятся в Git в целях безопасности!):
   - Файл ключа подписи (release-key.jks или android.keystore).
   - Файл google-services.json скопируй в папку android/app/.
5. ПРОВЕРЬ РАБОТУ:
   - Запусти локальный сервер разработки:
     npx vite
